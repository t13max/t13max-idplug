# T13max Heybox Line Reader

IDEA 2026.1 的实验性小黑盒状态栏阅读器。插件界面默认中文，可在菜单“语言 / Language”切换中英文，选择保存在 IDEA 应用设置中。网页原文不翻译。

## 登录与阅读

1. 从磁盘安装 `t13max-idplug-heybox-0.2.2.zip`，重启 IDEA。
2. 点击底部阅读器文字，选择“扫码登录 / Scan QR to sign in”。先在状态栏显示“正在检查登录状态”：已有有效会话时直接加载推荐，不弹扫码窗口；连续三次检测到官方登录按钮后才显示二维码小窗口。检查超时会提示打开官方页面，不将超时当作未登录。完整官方页面在后台加载，二维码图像只复制到内存，不解码、不保存到磁盘、不上传到其他服务。
3. 用小黑盒 App 扫码并在手机确认。二维码过期时点击“刷新二维码 / Refresh QR”；无法提取或需要额外验证时点击“官方页面 / Official Page”，手动完成官方登录流程。插件不会代替你同意协议，不输入密码、不收集验证码，也不自行生成登录二维码。

二维码提取和阅读提取任一路径检测到已登录，都会立即结束扫码并隐藏窗口。关闭窗口本身不会登录；二维码不可用时窗口显示明确提示。
4. 检测到登录成功后自动隐藏网页窗口，菜单中的“扫码登录”变为“登出 / Sign out”。“首页推荐 / Home Feed”使用当前官方网页账号的首页，不承诺与手机 App 的推荐完全一致。
5. 条目采用单字母标记：P 帖子列表、T 标题、B 正文、C 主评论（回复帖子）、R 楼中楼（回复评论），例如 `C [3/20] 评论文字`。不显示作者昵称、等级或正文摘要。`Alt+A` / `Alt+D` 切换条目，`Alt+S` 进入或退出帖子并恢复原列表位置；这些导航操作不再出现在点击菜单中。不渲染图片、视频，不保证展示全部折叠评论。
6. 列表菜单中“刷新列表 / Refresh List”刷新，“首页推荐 / Home Feed”返回账号首页，“选择专区 / Choose Community...”提供首页已显示的社区（必要时自动加载首页后弹出选择框）；其他社区可通过官方页面手动浏览。已检查的官方页面只有“智能排序”，未找到独立“热门”选项，本版不提供伪造的热门排序，也不把账号首页当作热门榜。

## 刷新结果

刷新相同页面使用 JCEF 的忽略缓存重载，等待新文档加载后才开始提取，避免旧文档被当成本次结果。返回列表后刷新会重新加载列表地址。刷新后等待至少八秒且连续提取稳定，再比较条目顺序、地址和文字；首次显示新列表时回到第一帖并重置横向滚动位置；此后可以正常翻页，后台确认完成不再重置阅读位置或横向滚动，菜单保留“内容已更新”或“内容未变化”的刷新结果。该比较只证明网页提取结果是否变化，不保证官方每次都推送新帖子。超时会保留旧列表并明确提示，不能将其当作刷新成功。

## 操作

| 操作 | 默认快捷键 |
| --- | --- |
| 显示/隐藏 | Alt+E |
| 下一条 | Alt+D |
| 上一条 | Alt+A |
| 进入/退出帖子 | Alt+S |

滚轮按实际字体像素宽度横向移动当前一行，显示宽度 310px。短文本不滚动，长文本到末尾对齐右侧就停止，不再滑到空白；切换条目后回到开头。前缀反斜杠已移除。可在 IDEA Keymap 中修改快捷键；如果升级后旧的自定义绑定仍在，请在 Keymap 搜索 Heybox 检查绑定。读取更多内容可打开原网页手动滚动，关闭窗口后重新提取。上一条/下一条仅在当前已加载的最多 200 条内容中循环，不会自动无限翻页。

## 登录状态与隐私

- 多个项目共用插件浏览器，不与外部 Chrome 或 Codex 浏览器自动共享登录；首次安装须重新扫码。
- 0.1.4 起，确认登录后将限定小黑盒域名的 Cookie（含 HttpOnly）保存在 IDEA PasswordSafe，不保存密码、不上传凭据、不写入项目或日志。首次升级须扫码一次以建立快照；关闭窗口不登出。重启后先恢复会话再加载官方首页验证，不自动弹出二维码。更新或重新安装插件通常不会清除 IDEA 的安全存储。
- 保留 Cookie 原始有效期；本地快照超过三十天不再恢复。官网使会话失效、清除 IDEA 配置或 PasswordSafe 使用仅内存保存模式时仍需重新扫码，不承诺永久免登录。保存/恢复失败可在菜单查看提示；请确保 IDEA 的密码保存设置允许持久保存。实际跨重启效果仍需在 IDEA 中验收。
- 登录确认后可点击“登出”：先删除本插件保存的会话，再调用官方账号菜单退出，确认未登录后清除阅读缓存；失败时提示处理，不伪装为已退出。不会批量删除 Cookie、外部浏览器或公共缓存。安全存储删除失败会保留菜单警告。JCEF 会话仍可能与其他使用小黑盒网页的插件共享，官网登出的服务端影响范围由官网决定。
- 启动 IDEA 时仅在发现可恢复快照后自动加载官方首页。导航/刷新至少间隔两秒；加载后最多检查 DOM 30 秒，登录窗口最多五分钟。DOM 检查不会额外请求 API，官方页面自身仍可能发出请求。
- 仅适配官方网页中已有内容；没有使用非公开 API、逆向请求签名或绕过验证码、限流。页面结构变化、风控和网络限制可能导致不可用，此时打开原网页查看提示。
- 此方案需要 JCEF，会占用浏览器进程和内存。暂未验证 IDEA 内扫码成功、隐藏窗口持续读取和跨重启会话保持；构建通过不能代替这些人工验收。
- 二维码小窗口使用离屏 JCEF，提取器只接受官方登录提示附近唯一的正方形图像，不拿社区页面的 App 下载二维码充数。跨域图像无法复制、页面结构变化或二维码无法识别时会明确提示打开官方页面。该适配已进行离线测试，仍需真实 IDEA 内扫码验收。

## 打包

在 Windows Git Bash 中执行：

```bash
cd /e/T13maxProjects/t13max-idplug/t13max-idplug-heybox
bash ./build-plugin.sh --skip-clean
```

默认使用 `D:\Program Files\JetBrains\IntelliJ IDEA 2026.1` 自带 JBR，也可传入安装目录或设置 `IDEA_PATH`。脚本执行离线测试、打包和插件结构检查，输出 ZIP 路径及 SHA-256。

JavaScript DOM 提取测试不需要安装 npm 依赖，有 Node.js 时执行 `node --test src/test/js/reader.test.cjs src/test/js/login-qr.test.cjs`；当前打包脚本只自动运行 Java 测试。

复用 `GRADLE_USER_HOME`（本机为 `E:\GradleUserHome`）。不清理公共下载缓存；默认 `clean` 仅清理本模块 `build`。新模块独立使用 Gradle 9.1.0，不修改旧模块的根构建配置。
